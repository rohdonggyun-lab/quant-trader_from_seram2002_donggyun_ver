# quant-trader — 대형주 모멘텀 자동매매 (모의투자)

시가총액 상위 종목 중 최근 몇 달 강했던 10종목을 들고, **일주일에 한 번** 순위를 다시 매겨
밀려난 종목만 바꾸는 프로그램입니다. 주문은 한국투자증권 Open API **모의투자 계좌**에 냅니다.
시세는 KRX Open API(일별 전 종목)에서 받습니다.

seram2002의 quant-trader(장중 단타 전략 시험 틀)에서 출발했고, 증권사 연결·주문 확인·알림 부분을
살려서 주 1회 교체 방식으로 바꿨습니다. 예전 단타 전략은 git 기록(커밋 `3f148d3` 이전)에 남아 있습니다.

- 결과 보고서와 일지(`results/`), 장부와 시세(`data/`, `backtest/data/`)는 git에 올리지 않습니다.

## 전략: 대형주 모멘텀 v1 (`momentum.py`)

| 항목 | 규칙 |
|---|---|
| 종목 범위 | 신호일 시가총액 상위 100개 보통주 (우선주 제외) |
| 순위 | 최근 120거래일 수익률, 가장 최근 5거래일은 빼고 계산. 높은 순 |
| 교체 | 매주 마지막 거래일(신호일) 종가로 순위 → 다음 거래일에 사고팖 |
| 보유 | 10종목. 살 때마다 전체 자산의 1/10 |
| 매도 | 순위가 20위 밖으로 밀리거나 시가총액 상위 100에서 빠지면 |
| 시장 필터 | 신호일 근사 코스피가 60일 이동평균 아래면 전부 팔고 현금으로 기다림 |

규칙을 바꾸면 `momentum.py`의 `VERSION`을 올립니다. 버전은 매매 기록에 남습니다.

### 백테스트 근거 (`backtest/large_cap_momentum.py`)

2022-01 ~ 2026-11, 비용(수수료 0.015%×2, 슬리피지 0.05%×2, 매도세 0.20%) 포함.

| | 연수익률 | 최대낙폭 |
|---|---|---|
| 이 전략 | 30.0% | −37.3% |
| 대형주 균등 (비용 0) | 8.0% | −38.5% |
| 근사 코스피 | 11.0% | −46.3% |

미리 정한 12개 조합 중 통과한 3개 중 하나이고, 슬리피지 2배·교체 요일 변경에도 통과했습니다.
기간이 5년뿐이고 2025~26년 상승장 영향이 커서, 실제 성과는 이보다 낮다고 보는 게 안전합니다.
같은 폴더의 `weekly_reversal.py`, `close_entry_reversal.py`는 탈락한 단기 반전 전략 기록입니다.

## 하루 흐름 (`run.py`)

1. KRX Open API에서 어제까지 빠진 날의 시세를 받습니다. KRX는 다음 날 아침에 올라오므로,
   아직 없으면 10분마다 다시 시도합니다 (14:30까지). 휴장일은 한국투자증권 일별 시세로 확인합니다.
2. 지난주 신호일의 교체를 아직 안 했으면 **교체일**입니다.
   - 아침에 계속 보유 / 매도 / 매수 후보를 슬랙으로 알립니다.
   - 15:10 매도 (시장가, 체결 확인)
   - 15:12 매수 (최유리지정가, 2초씩 체결 확인 후 미체결 잔량 취소 — 쫓아 사지 않음)
   - 15:17 못 산 자리를 한 번 더 시도. 그래도 비면 다음 주에 채웁니다.
3. 교체일이 아니면 보유 현황만 알리고 끝납니다 (대부분의 날).

교체일을 놓치면(컴퓨터가 꺼져 있었다면) 그 주 안의 다음 실행 때 같은 신호로 교체합니다.
시간표는 `config.py`에 있습니다.

## 파일 구조

```
run.py                 실행기 (하루 한 번 켜면 할 일을 하고 종료)
momentum.py            전략 계산 (백테스트와 실매매가 같은 코드를 씀)
config.py              자금, 비용, 시간표
report.py              data/momentum/ → results/momentum.md 보고서
trader/
  kis_client.py        한국투자증권 Open API (시세, 잔고, 주문, 취소, 체결 조회)
  broker.py            주문과 체결 확인, 장부 (data/momentum/state.json, trades.csv)
  market_data.py       매일 KRX 시세 받기
  notifier.py          화면 + 날짜별 로그(data/logs/) + 슬랙
backtest/
  fetch_data.py        KRX Open API로 과거 일별 시세 받기 (처음 한 번)
  large_cap_momentum.py  이 전략의 백테스트
```

## 사용법

### 처음 한 번

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

`.env.example`을 복사해 `.env`를 만들고 값을 채웁니다 (git에 올리지 않음).

| 항목 | 내용 |
|---|---|
| `KIS_APP_KEY`, `KIS_APP_SECRET` | 한국투자증권 모의투자 앱키 |
| `KIS_ACCOUNT_NO` | 모의투자 계좌번호 `12345678-01` |
| `KRX_API_KEY` | KRX Open API 인증키 (유가증권·코스닥 일별매매정보 서비스 신청 필요) |
| `SLACK_BOT_TOKEN`, `MOCK_SLACK_CHANNEL` | 슬랙 봇 토큰과 알림 채널 |

과거 시세를 한 번 받습니다 (약 2시간, 하루 2번 호출 × 거래일 수).

```
python backtest/fetch_data.py 20210104 20261120
```

### 매일

```
python run.py --check     (선택) 주문 없이 오늘 교체한다면 무엇을 사고팔지 출력
python run.py             아침에 켜 두면 할 일을 하고 종료 (교체일은 15:19쯤)
python report.py          (선택) 결과 보고서 갱신
```

- 교체일에는 15:10~15:19에 컴퓨터가 켜져 있어야 합니다. `run.bat`을 작업 스케줄러에 등록해 두면 편합니다.
- 장부는 파일에 저장되므로 껐다 켜도 이어집니다. 모의계좌는 이 프로그램 전용으로 씁니다.
  다른 경로로 산 종목은 건드리지 않고 알리기만 합니다.

## 연결과 오류 처리

- 조회 중 연결이 끊기면 새 연결로 다시 조회합니다. 호출 제한 오류도 잠시 뒤 다시 시도합니다.
- 주문은 자동으로 다시 보내지 않습니다. 응답 없이 끊기면 잔고로 체결 여부를 확인합니다.
- 시작할 때 장부와 계좌를 맞춰 보고, 어긋나면 계좌 기준으로 고치고 알립니다.
- 시세를 못 받거나 휴장일이면 그날은 주문하지 않습니다.
- 백테스트는 종가 거래를 가정했지만 실제로는 15:10~15:17 가격에 거래합니다.
